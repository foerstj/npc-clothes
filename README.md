# npc-clothes

Providing NPC clothes for the player to wear.

Featuring 35 pieces of clothing, implemented as low-level body armor. Most have no equip requirements at all.\
The clothes are part of the pcontent pool and will appear mostly in beginner area shops & loot.

## Installation
- Put the NPC Clothes.dsres file into the Resources or DSLOA directory of your game installation.
- The Mart dsmap & dsres are optional, they contain a map for multiplayer mode where you can buy all clothes (without enchantments) directly at a dedicated shop for convenience.
- The .de.dsres is also optional, containing German translations.
